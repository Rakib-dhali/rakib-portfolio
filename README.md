## 🌌 About The Project

This is my personal developer portfolio, designed to showcase my journey, skills, and featured projects as a Full-Stack Developer. It features a sleek dark mode aesthetic with glassmorphism UI elements, subtle grain textures, and fluid GSAP scroll animations. 

Built from the ground up to be performant, accessible, and visually striking, it serves as both a resume and a demonstration of my front-end capabilities.

### ✨ Key Features

- **Dynamic Animations**: Smooth, high-performance scroll animations and page transitions powered by GSAP and Framer Motion.
- **Modern UI/UX**: Premium design system utilizing Tailwind CSS, glassmorphism (`backdrop-blur`), and glowing hover effects.
- **Fully Responsive**: Flawless experience across all devices (Desktop, Tablet, Mobile).
- **Smooth Scrolling**: Integrated Lenis for a buttery-smooth scrolling experience.
- **Component Driven**: Modular React architecture with reusable UI components.

## 🚀 Getting Started

To get a local copy up and running, follow these simple steps.

### Prerequisites

You need to have Node.js and npm (or yarn/pnpm) installed on your machine.
* npm
  ```sh
  npm install npm@latest -g
  ```

### Installation

1. Clone the repo
   ```sh
   git clone https://github.com/Rakib-dhali/rakib-dhali-portfolio.git
   ```
2. Install NPM packages
   ```sh
   npm install
   ```
3. Start the development server
   ```sh
   npm run dev
   ```
4. Open [http://localhost:3000](http://localhost:3000) in your browser.

## 📂 Project Structure

- `/src/app` - Next.js App Router layout and pages
- `/src/sections` - Major page sections (Hero, About, Tech, Experience, Projects)
- `/src/components` - Reusable UI components (Buttons, Social Links, Nav)
- `/src/assets` - Static assets (Images, SVGs, Fonts)
